## ✨ Overview

This chapter introduces the basic HTML tags used to add content to a webpage.

You will learn how to use headings, paragraphs, links, images, text formatting, line breaks, horizontal lines, subscripts, superscripts, and preformatted text.

## 🧱 HTML Element

An HTML element consists of a starting tag, content, and an ending tag.

```html
<body>
  Content
</body>
```

- `<body>` is the opening tag.
- `Content` is the information shown on the webpage.
- `</body>` is the closing tag.

## ⚙️ HTML Attributes

HTML attributes give extra information to an HTML tag.

Example:

```html
<a href="https://tanmayxyz.com">TANMAY</a>
```

Here, `href` is an attribute of the anchor tag. It tells the browser where the link should go.

> Attributes can use either single quotes or double quotes.

## 🔠 Heading Tags

HTML provides six heading levels.

```html
<h1>Most important heading</h1>
<h2>Second most important heading</h2>
<h3>Third most important heading</h3>
<h4>Fourth most important heading</h4>
<h5>Fifth most important heading</h5>
<h6>Sixth most important heading</h6>
```

> `<h1>` is the most important heading, while `<h6>` is the least important.

## 📄 Paragraph Tag

The paragraph tag is used to write text in paragraph form.

```html
<p>This is a paragraph.</p>
```

## 🔗 Anchor Tag

The anchor tag is used to add links to a webpage.

```html
<a href="https://www.google.com/">Click me</a>
```

## 🖼️ Image Tag

The image tag is used to display images.

```html
<img src="image.png" alt="Image" width="500" height="600">
```

- `src` specifies the image path.
- `alt` displays alternate text if the image cannot load.
- `width` and `height` set the image size.

You can also use an image URL from the internet.

```html
<img src="https://example.com/image.png" alt="Google logo" width="500" height="600">
```

## ✍️ Bold, Italic, and Underline Tags

These tags help highlight text.

```html
<b>This is bold text</b>
<br>

<i>This is italic text</i>
<br>

<u>This is underlined text</u>
```

## ↩️ Break Tag

The `<br>` tag creates a line break.

```html
Hello
<br>
World
```

## 🔎 Big and Small Tags

The `<big>` and `<small>` tags change the text size.

```html
<big>Hello World</big>
<br>

<small>Hello World</small>
```

## ➖ Horizontal Rule Tag

The `<hr>` tag creates a horizontal line to separate content.

```html
<hr>
```

## ₂ Subscript and Superscript

Use `<sub>` for subscript and `<sup>` for superscript.

```html
H<sub>2</sub>O
<br>

x<sup>2</sup>
```

## 📌 Preformatted Text Tag

HTML normally ignores extra spaces and new lines. The `<pre>` tag keeps them exactly as written.

```html
<pre>
This is written
using the pre
tag.
</pre>
```

## ✅ Important Notes

- Use heading tags to define headings, not only to make text large or bold.
- Always add `alt` text to images.
- Use the `href` attribute inside the anchor tag to add a link.
- `<br>` does not need a closing tag.
- `<img>` does not need a closing tag.
- Keep your HTML code properly indented for better readability.

## 🚀 How to Run the Program

1. Create a file named `index.html`.
2. Write or paste your HTML code into the file.
3. Save the file.
4. Open `index.html` in any web browser.
5. View the output and practice changing the tags.
